# Credits and project history

Nuzlocke has been developed across multiple generations of Gen1Recomp. The Generation 3 port builds on that work; it does **not** replace or erase authorship of the Generation 1 and 2 implementation.

## Original and maintained Generation 1/2 work

- **[bryanthaboi](https://github.com/bryanthaboi)** — original Nuzlocke mod creator and foundation for the challenge-rule system.
- **[Stone696](https://github.com/Stone696)** — maintained and significantly expanded the Generation 1/2 Nuzlocke mod, including its rule systems, randomiser, compatibility contracts, diagnostics and releases; also maintains a Shiny Pokémon fork.
- **[masterwebx](https://github.com/masterwebx)** — author of the original Shiny Pokémon mod, part of the technical and design lineage of Nuzlocke's shiny functionality and external shiny compatibility.

These credits apply to their original contributions, not as a claim that these developers authored the new Generation 3 implementation.

## Generation 3 — v3.0.0-BETA

- **[Deluxe0111](https://github.com/Deluxe0111)** — Generation 3 port and integration: the independent FRLG/RSE runtime and native game hooks; adapted core rules, clauses, randomiser and player tools; new Shiny/Hardcore playstyle integrations, Gen 3-specific rules and setup, Untamed-Advanced overworld-wild interoperability, Run Journal, results/memorial sharing, Mod Support diagnostics and hidden developer/testing utilities.

Development was conducted with AI-assisted coding and testing. Credit for the Gen 3 port belongs to Deluxe0111 as the project contributor/maintainer; earlier contributors retain full attribution for their work.

## Related projects

- **[Gen1Recomp](https://github.com/bryanthaboi/gen1recomp)** — the game recompilation/mod platform. This Nuzlocke repository is a mod, not the base engine.
- **[Untamed Advanced](https://github.com/Deluxe0111/Untamed-Advanced)** — optional Gen 3 mod whose supported overworld spawn hooks are integrated with the v3 Nuzlocke randomiser.
- Third-party providers and compatible mods retain their respective authorship; optional compatibility is not a transfer of ownership.

## Historical release records

The **[changelog](CHANGELOG.md)** and **[legacy Gen 1/2 user guide](docs/USER_GUIDE.md)** retain earlier releases and functionality for reference. The new **v3.0.0-BETA** release notes document only the current Generation 3 work and do not retroactively attribute old releases to the port.
