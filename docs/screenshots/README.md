# Runtime screenshot capture guide

Final user-facing screenshots should be captured from the actual release candidate in Gen1Recomp.

## Capture list

1. `gold-setup-expanded.png` — Gold Setup with one section expanded and another collapsed.
2. `yellow-rules-selection.png` — Yellow NUZ RULES highlighting a multi-state/numeric rule.
3. `enc-tracker-log.png` — ENC TRACKER LOG with meaningful encounter results.
4. `enc-tracker-map.png` — ENC TRACKER MAP/area view.
5. `rby-nuz-status.png` — R/B/Y Trainer Card NUZ STATUS.
6. `catch-info.png` — CATCH INFO for a tracked Pokémon.
7. `rule-enforcement.png` — a clear normal-gameplay enforcement message.
8. `gold-nuz-status.png` — Gold Start-menu status entry/screen.

## Presentation

- Capture directly from Gen1Recomp runtime.
- Prefer the native game frame or a clean integer-scale crop.
- Do not include unrelated desktop/window clutter when a clean crop is possible.
- Keep the same aspect ratio and scale across the screenshot set.
- Do not stage a screenshot that shows a rule/result different from the actual tested build.
